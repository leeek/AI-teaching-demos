AI Teaching Demos for Marketing Courses

A shared collection of interactive teaching demos built with AI for use in marketing courses. Faculty can browse existing demos, create new ones using the starter prompt, and contribute examples back for colleagues to adapt.

Getting Started

Use an existing demo

Open a demo from the library, download what you need from GitHub, test it in your browser, and upload it to Canvas.

Create your own

Use the starter prompt in Claude or another AI tool, then save and test the generated HTML file.

Contribute

See the contribution guide for the folder structure and README fields to include.

For Students

Students do not interact with this repository directly. They receive demos through Canvas or other course materials as usual.
