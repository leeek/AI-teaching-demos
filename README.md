# AI Teaching Demos for Marketing Courses

This repository is a shared collection of interactive teaching demos built with AI for use in marketing courses. Instructors can browse existing demos, create new ones using the starter prompt, and contribute their own examples back so colleagues can adapt, learn from, and reuse them.

## Links

- [Public demo site](https://leekevin.io/AI-teaching-demos/) for interactive demos
- [Dropbox folder](https://www.dropbox.com/scl/fo/clur2vtwr9wl7pv919ssk/ANAAjBrNTQrAOBdBSjqk99s?rlkey=7ei6838ij2x3f5hw29yxqpe7g&dl=0) for convenient downloading of demo files. It is a copy of the `demos/` folder in this repository.

## Demo Library

- [Price Elasticity Demo](./demos/price-elasticity/price-elasticity-demo.html) - linear demand, price elasticity, and the revenue-maximizing price.
- [Segmentation & Targeting Game](./demos/segmentation-targeting-game/segmentation-targeting-game.html) - define MECE segments, choose whom to advertise to, and see why targeted ads overstate their own effect (MKT 300).
- [Conjoint Design Studio](./demos/conjoint-design-studio/conjoint-design-studio.html) - generate and check product profiles for a classroom conjoint study (Pricing).
- [Silicon Subject Lab](./demos/silicon-subject-lab/silicon-subject-lab.html) - build and interview synthetic consumers one at a time without mean regression (Strategic Brand Management).
- [Brand Positioning Analysis](./demos/brand-positioning-analysis/brand-positioning-analysis.html) - compare brand identity with brand image against an intended positioning (Strategic Brand Management).
- [Customer Lifetime Value Tools](./demos/customer-lifetime-value-tools/) - cash-flow timing, survivor tables, BG parameters and the coin shake-out (MKT 626).

## Getting Started

### Use an existing demo

Browse the `demos/` folder and open any demo folder that looks useful for your class. Download the files you need, test the HTML file in your browser, and upload it to Canvas for students as you normally would.

### Create your own

Open `Teaching App Prompt.txt`, paste the prompt into Claude or another AI tool, and fill in the bracketed sections with your concept, desired interaction, and course context. Ask the AI tool to generate the complete HTML file, save the output as an `.html` file, and test it by opening it in your browser.

### Contribute

We'd love to see what you come up with! If you'd like to share your demo, see `CONTRIBUTING.md` for how to add a demo to this shared library.

## For Students

Students do not interact with this repository directly. They receive demos through Canvas or other course materials as usual.
