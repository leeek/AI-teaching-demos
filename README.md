# AI Teaching Demos for Marketing Courses

This repository is a shared collection of interactive teaching demos built with AI for use in marketing courses. Faculty can browse existing demos, create new ones using the starter prompt, and contribute their own examples back so colleagues can adapt, learn from, and reuse them.

## Getting Started

### Use an existing demo

Browse the `demos/` folder and open any demo folder that looks useful for your class. Download the files you need, test the HTML file in your browser, and upload it to Canvas for students as you normally would.

### Create your own

Open `Teaching App Prompt.txt`, paste the prompt into Claude or another AI tool, and fill in the bracketed sections with your concept, desired interaction, and course context. Ask the AI tool to generate the complete HTML file, save the output as an `.html` file, and test it by opening it in your browser.

### Contribute

We'd love to see what you come up with! If you'd like to share your demo, see `CONTRIBUTING.md` for how to add a demo to this shared library.

## For Students

Students do not interact with this repository directly. They receive demos through Canvas or other course materials as usual.
